## ADDED Requirements

### Requirement: 加载待编辑商品数据预填表单
编辑页 SHALL 根据传入的商品 ID 调用 `GET /api/product/detail` 加载数据，并用其预填共享表单（图片、描述、价格、分类、地区、联系方式）。

#### Scenario: 加载成功并预填
- **WHEN** 编辑页接收到有效商品 ID 且请求成功
- **THEN** 表单各字段展示该商品的已有数据，已上传图片直接展示为已上传状态（无需重新上传）

#### Scenario: 加载失败
- **WHEN** 请求返回错误或商品不存在
- **THEN** 展示"加载商品失败"提示

### Requirement: 编辑表单校验
编辑表单 SHALL 复用发布表单的校验规则（至少一张图片、描述非空、价格非空、地点已选、联系方式非空）。

#### Scenario: 编辑时清空必填字段
- **WHEN** 用户清空描述字段后提交
- **THEN** 提交被阻止，提示"请填写商品描述"

### Requirement: 提交更新
校验通过后 SHALL 调用 `PUT /api/product/update` 提交更新后的商品数据，成功后返回上一页（我的发布列表）。

#### Scenario: 更新成功
- **WHEN** 提交请求返回成功信封
- **THEN** 展示"保存成功"提示并自动返回上一页

#### Scenario: 更新失败
- **WHEN** 提交请求返回错误信封或网络错误
- **THEN** 展示"保存失败，请重试"提示，停留在编辑页且表单内容保留
