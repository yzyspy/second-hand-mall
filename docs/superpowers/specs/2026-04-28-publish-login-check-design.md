# 发布商品前登录检查设计

## 背景

用户在未登录状态下进入发布页面时，需要引导用户先完成微信登录才能发布商品。

## 流程

```
用户点击发布tab → 进入发布页 → 检查登录状态
                                    ↓
                            已登录 → 正常显示发布表单
                                    ↓
                            未登录 → 弹窗提示
                                    ↓
                        用户点击"取消" → 留在发布页
                        用户点击"去登录" → 跳转个人中心tab
```

## 弹窗配置

- **标题**: 请先登录
- **内容**: 发布商品需要登录
- **按钮**: 取消 / 去登录

## 技术实现

修改文件: `mall-mini/miniprogram/pages/publish/publish.ts`

1. 在 `onShow` 生命周期中调用 `wx.getStorageSync('token')` 检查登录状态
2. 未登录时调用 `wx.showModal` 显示弹窗
3. 用户点击确定后调用 `wx.switchTab({ url: '/pages/my/my' })` 跳转个人中心

## 登录后行为

登录成功后用户留在个人中心页面，需要手动点击发布tab重新进入发布流程。
